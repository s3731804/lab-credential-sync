Lab Credential Sync

This extension needs a small local helper, installed once, to write credentials to ~/.aws/credentials directly (no Downloads folder involved). Source and install instructions:

View setup instructions on GitHub →

After running the install script, reopen this popup — it will say "Helper connected" once set up.

What this does: once the helper is installed and sync is on, start your Learner Lab as normal and reveal the AWS CLI credentials yourself using Show. This extension only reads credentials already visible on the page — it never clicks Show for you. Credentials never leave your device.
